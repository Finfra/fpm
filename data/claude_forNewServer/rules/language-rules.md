- 높임말 대신 줄임체 선호 (ex: "~합니다" → "~함")
- 별도 요청 없으면 요점 중심, 목록 형태로 간결 정리

## 표현

- 예시 표시는 `ex) ` 사용 ("예를 들어," 금지)
- 불확실한 정보는 `(검증 필요)`로 명시
- **비한국 한자 표기 금지 (Issue314)**: 한자어는 **한글 표기**가 기본. 한자를 꼭 써야 하면 **한국 정자(正字)만** 사용. 일본 신자체·중국 간체 금지.
    - ✅ 상태 / (부득이 시) `狀態` — ❌ `状態`(일본 신자체) · ❌ `状态`(중국 간체)
    - ✅ 실행 / `實行` — ❌ `実行` · ❌ `实行`
    - 적용 범위: 채팅 응답·문서 본문뿐 아니라 **도구 호출 파라미터**(Bash `description`, TodoWrite 항목, 커밋 메시지, HTML `<title>`)까지 전부. 실발생 사례가 Bash `description` 필드였음 — 짧은 영문 문장에 "state" 대신 `状態` 가 섞임
    - 발견 시: 즉시 한글로 교정. 다국어 토큰 누출이므로 같은 응답 내 다른 표현도 함께 점검
- **파일·경로 참조는 markdown 링크 1방식으로 통일**: `[표시명](상대경로)` 형식. 백틱 코드 span(`` `path` ``)으로 감싸지 말 것. 한 응답 안에서 일부는 링크·일부는 백틱으로 혼용 금지.
    - **적용 범위 = 채팅 응답 + 문서 본문 둘 다**. 문서 본문에서도 백틱 대신 링크를 쓴다(IDE·Obsidian 클릭 호환 — [`refs-rules.md`](../_doc_arch/rules-ondemand/refs-rules.md) 와 동일 취지)
    - **예외**: `Issue.md` 의 `* plan:`·`* task:` 필드는 **백틱 표기**가 규약이다 — 포맷 SSOT 는 [`issue-g.md`](issue-g.md). 기계 파싱 대상이라 링크로 바꾸면 소비처(issue-map)가 깨진다 라인 참조는 `[file.ts:42](path#L42)`. (VSCode 확장 컨텍스트 규칙과 동일 — 본 룰로 전 프로젝트·전 환경 박제)
    - **href 기준 = 워크스페이스 루트 상대경로 (필수)**: 링크 href(괄호 안 경로)는 반드시 **워크스페이스 루트부터의 전체 상대경로**여야 함. `[project-necessity.md](project-necessity.md)`처럼 **basename만 href에 넣으면 루트에서 그 파일을 찾다 실패 → 죽은 링크**(VSCode 채팅 webview는 클릭 시 무반응). 표시명은 basename으로 축약해도 되나 **href는 서브폴더 포함 full path 유지**: `[project-necessity.md](_doc_base/background/project-necessity.md)`. cwd 기준·basename 기준 상대경로 금지.
    - **볼트(`~/_doc`) 파일은 예외**: Obsidian 볼트 파일은 워크스페이스 밖이라 상대경로 불가 → hub `/ob` http 브리지 경유([`ob-link-rules.md`](../_doc_arch/rules-ondemand/ob-link-rules.md)). 프로젝트 내 파일만 위 워크스페이스 상대경로 규칙 적용.

## ⚠️ 경로를 **줄 맨 앞**에 둘 때 — `/` 대신 `~/` (Issue39 · 2026-08-06 실발생)

Zed Agent Panel(claude-acp)은 첫 글자가 `/` 인 **사용자 입력**을 슬래시 커맨드로 해석해 **전송 자체를 취소**한다(`… is not a recognized command in claude-acp`). `$HOME/_git/…` 를 붙여넣는 지극히 정상적인 동작이 그대로 막힌다.

* **회피는 표기 하나** — `~/_git/…` 로 쓰면 첫 글자가 `/` 가 아니라 구조적으로 면역이다. 이미 문서·룰 전반이 쓰는 표기라 바꿀 습관도 없다. 굳이 절대경로가 필요하면 `/` 앞에 **공백 한 칸**
* **Claude 의 의무** — 사용자에게 **경로를 답으로 요구하는 질문**(*"어느 폴더?"*, *"경로 알려주세요"*)을 할 때는 `~/` 표기 주의 1줄을 함께 붙인다
* **왜 1줄이 필요한가** — 차단은 **클라이언트 측**이라 에이전트에는 아무 신호도 오지 않는다. 트랜스크립트에 흔적이 0건이라 이쪽은 "유휴", 사용자는 "멈춤"으로 보고, 원인이 입력 문자열이라 **재시작해도 같은 자리에서 막힌다**
* 진단 기록: [`debug_TECH.md`](../../_git/___pm/_doc_work/debug_TECH.md) 2026-08-06 항목 · 도구 오탐 동반 수정 prj5#Issue39

## 리터럴 지시 준수 대응 (Opus 4.8 이후)

- **종료 조건 명시**: "완료되면 중단하라", "3회 재시도 후 실패 보고"

- 에이전트 루프는 반드시 중단 조건 포함
